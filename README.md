# Kurd Sport Live ⚽️📺

ئەپێکی وەرزشی پێشکەوتووە بۆ سیستەمەکانی ئەندرۆید و ئایۆس بە بەکارهێنانی فلاتەر (Flutter).

## تایبەتمەندییە سەرەکییەکان:
* **پەخشی ڕاستەوخۆی یارییەکان:** بینینی لیستی یارییەکان و پەخشکردنیان بە ڕوکاری ڤیدیۆ پلەیەر (`video_player`).
* **سیستەمی پێشبینییەکان:** پێشبینیکردنی ئەنجامی یارییەکان و بەدەستهێنانی خاڵ.
* **سیستەمی خەڵات:** بەدواداچوونی خاڵەکان و بەشداریکردن لە دیارییەکاندا.

## تەکنەلۆجیاکانی بەکارهاتوو:
* Flutter (Dart)
* Video Player & Chewie
